# Paper draft — workshop / arXiv version

`main.tex` is a complete first draft. Every number in it comes from
`numbers.tex`, and every figure from `figures/`, both regenerated by:

```bash
python paper/make_figures.py
```

Nothing is retyped by hand, so re-running after new data updates the draft.

## Compiling

No LaTeX is installed on this machine. Easiest route:

1. Go to overleaf.com → New Project → Upload Project
2. Upload this `paper/` folder (main.tex, numbers.tex, figures/)
3. Set `main.tex` as the main document and compile with pdfLaTeX

Locally instead: `brew install --cask mactex-no-gui`, then `pdflatex main.tex`
twice (the second pass resolves references).

## Formatting for a specific venue

The draft uses plain `article` two-column, roughly 8 pages. Most workshops
require their own style file: drop `main.tex`'s body into their template and
keep `\input{numbers}` plus `figures/`.
